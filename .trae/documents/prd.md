## 1. 产品概述

殡葬墓园陵园管理系统是一款面向陵园管理机构的客户端软件，用于统一管理墓位销售、安葬和祭扫服务全流程。系统通过电子墓区分布图和墓位状态管理，实现从购墓合同登记、安葬预约、立碑刻字到祭扫分流、代客祭扫、绿化养护排期及费用续缴的全链路数字化管理，提升陵园运营效率和服务品质。

- 目标用户：陵园管理人员、销售人员、客服人员、养护人员
- 核心价值：实现墓位全生命周期数字化管理，减少人工错漏，提升客户服务体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 系统管理员 | 系统初始化 | 全部模块读写、系统设置、用户管理 |
| 销售专员 | 管理员分配 | 墓位销售、购墓合同登记、费用管理 |
| 客服专员 | 管理员分配 | 安葬登记、祭扫预约、代客祭扫、客户回访、迁墓处理 |
| 养护专员 | 管理员分配 | 绿化养护排期、墓区巡查 |
| 财务人员 | 管理员分配 | 费用管理、续缴提醒、账务统计 |

### 2.2 功能模块

1. **仪表盘**：数据概览、今日待办、墓位销售统计、安葬/祭扫日程、费用到期提醒
2. **墓区图**：电子墓区分布图、墓位状态查询、墓位筛选定位
3. **墓位销售**：购墓合同登记、墓位预订与成交、合同打印
4. **安葬登记**：安葬日期预约、立碑刻字登记、安葬流程跟踪
5. **祭扫预约**：祭扫预约分流、代客祭扫服务、祭扫记录管理
6. **绿化养护**：墓区绿化养护排期、养护任务管理、养护记录
7. **客户服务**：迁墓处理、客户回访、墓园档案查询
8. **费用管理**：管理费续缴提醒、费用账单、收款登记

## 3. 核心流程

### 3.1 墓位销售流程
客户咨询 → 墓位查询与推荐 → 实地看墓 → 墓位预订 → 签订购墓合同 → 付款登记 → 合同归档

### 3.2 安葬服务流程
安葬预约 → 立碑刻字登记 → 刻字确认 → 安葬前准备 → 安葬执行 → 安葬完成确认 → 档案归档

### 3.3 祭扫服务流程
祭扫预约 → 时段分配与分流 → 祭扫执行（或代客祭扫） → 服务反馈 → 记录归档

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深墨绿（#1B3A2D）+ 沉香金（#C4A35A）— 传达庄重、肃穆与尊贵
- 辅助色：暖灰白（#F5F3EF）、深炭灰（#2C2C2C）、淡松绿（#5A8F7B）
- 按钮风格：圆角4px，主按钮深墨绿底金色文字，次按钮白底墨绿边框
- 字体：标题用思源宋体/Source Serif Pro，正文用思源黑体/Noto Sans SC
- 布局风格：左侧固定导航栏 + 顶部工具栏 + 内容区，卡片式布局
- 图标风格：线性图标，统一2px描边，搭配金色点缀

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|

### 4.3 响应式设计
- 桌面优先设计，适配1920px/1440px/1280px宽度
- 平板端（768px-1024px）简化侧边栏为图标模式
- 移动端（<768px）底部Tab导航，简化信息展示

### 4.4 设计氛围
- 整体传达庄重、宁静、温暖的氛围，避免冰冷感
- 适当使用中国传统纹样作为装饰元素（如云纹、回纹边框）
- 墓区图采用鸟瞰园林风格，绿色植被与灰色墓碑和谐搭配
- 表单和列表保持简洁实用，数据密集区域使用充足留白
